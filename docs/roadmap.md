# Roadmap

## Android TV MVP

- [x] Native Kotlin Android TV launcher and remote-first home screen
- [x] Configurable startup URL with full-screen WebView
- [x] NDI source discovery and SDK receiver bridge
- [x] Full-screen aspect-fit video preview
- [x] Hybrid NDI/web view with a limited page-to-app viewport and source-selection bridge
- [x] User-assigned NDI source labels for page-triggered source selection
- [ ] Complete a Gradle build using the installed Android NDK and CMake
- [ ] Test on a physical Android TV device with both web and NDI sources
- [ ] Add production TV banner artwork and app icon
- [ ] Review SDK terms, attribution, and third-party notices for APK distribution

## Later

- [ ] Add source favorites and reconnection feedback
- [ ] Improve rendering performance using a Surface/texture path
